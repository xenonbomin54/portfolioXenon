## 프로젝트 하이라이트
*   **Swipe Interaction**: `Hammer.js` 라이브러리를 활용하여 모바일과 데스크톱 환경 모두에서 부드러운 스와이프 제스처를 구현했습니다.
*   **Vanilla Core**: 핵심 로직은 외부 프레임워크 없이 순수 자바스크립트(ES6+)로 작성되어 매우 빠르고 가볍습니다.
*   **Interactive UI**: 사용자 터치나 드래그에 즉각 반응하는 역동적인 인터랙티브 경험을 제공합니다.
*   **Responsive Design**: 기기 크기에 상관없이 최적의 레이아웃을 유지하는 반응형 디자인을 적용했습니다.

<br/>

## 기술 스택
- **Language**: HTML5, CSS3, JavaScript (ES6+)
- **Library**: **Hammer.js** (Touch Gestures Control)
- **Concept**: User Experience Focused & Gesture-Based Navigation

<br/>

## 주요 기능
- **제스처 제어**: `Swipe` 이벤트를 감지하여 페이지 내 섹션을 전환하거나 요소를 제어합니다.
- **실행 방법**: 화살표키로 카드를 움직여 내용 확인

<br/>
